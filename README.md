# Light In Darkness

Light In Darkness is a monochrome 2D platformer developed in Unity and C# as a university game project.

The game is built around different light-based mechanics that reveal otherwise hidden platforms and paths.

## Features

- Five playable levels
- Light-based platforming mechanics
- Hidden platforms revealed through light
- Moving light sources
- Lightning mechanics
- Monochrome visual style
- Main menu
- Level selection

## Controls

- WASD - Move
- Spacebar - Jump

## Technologies

- Unity
- C#

## Play the Game

A playable Windows build is available on itch.io:

## About the Project

Light In Darkness was developed as a university game project with a focus on experimenting with visibility, lighting and platforming mechanics.

Different light sources affect which parts of the environment are visible, requiring the player to use timing and observation to progress through the levels.
